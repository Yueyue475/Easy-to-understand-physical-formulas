场本身能被量子化吗？

麦克斯韦方程里的场是连续的波，光电效应里的光却是一份一份的。连续的东西怎么会长出“份”？答案不在光那边，而在场这边：场本身就是一堆振子，每个振子的能量只能一档一档地跳。

他当时卡在哪

1900 年，普朗克为了拟合黑体辐射谱，被迫假设振子的能量只能取 hν 的整数倍。1905 年，爱因斯坦把这个“份”推到光本身：光的发射和吸收，是一份一份进行的。1916 年密立根的光电效应实验、1923 年康普顿的 X 射线散射，都支持这个图像。

可这就留下一道难看的分裂。麦克斯韦的理论把光写成连续的电磁场：电场和磁场在空间里平滑起伏，能量密度正比于 E²+B²，可以取任意小的值。一个连续的场，凭什么只能整份地交出能量？如果光是波，振幅减小一点点，能量就该减小一点点，不该存在“最小的一份”。

1920 年代中期的量子力学也没接上。它处理的是“一个粒子在势场里怎么运动”，波函数描述这个粒子的概率。可光子的难处在于数目本身会变：原子可以发一个光子，也可以发两个；光子可以被吸收而消失。这已经超出“一个粒子”的框架。要说清楚，只能把场本身当成量子对象。

手上有什么工具

第一件工具是简谐振子。一根弹簧挂一个质量，偏离平衡位置越远，回复力越大；经典情况下能量连续，振幅多大能量就多大。1925—1926 年，海森堡和薛定谔分别给出了它的量子解：能量不能连续变，只能取一档一档的值，相邻两档的间隔是固定的。

第二件工具是普朗克-爱因斯坦关系：能量等于 h 乘频率；而频率与角频率只差一个 2π，所以一份能量也等于 ħ 乘角频率。

第三件是傅里叶的想法：任何一段复杂的波，都能拆成一堆简单正弦波的叠加。每一列正弦波有固定的波长和频率，就像一个独立的振子。

数学小站：一个场为什么像一堆弹簧

把空间划成许多小格，每格放一个场值。场值偏离零，就像弹簧被拉开，需要储存能量；相邻格子的场值不一样，互相拉扯，这一份拉扯也储存能量。

然后把整段场按正弦波拆开。每一列正弦波是一个“模式”，波长固定，频率也就固定；分解之后，各个模式互不耦合，每一个都单独地做简谐振动。

于是连续的场被拆成了一串互不干扰的振子。量子化一个场，就是量子化这串振子。

每个格点挂一个振子，相邻振子用弹簧相连。一个正弦模式，就是整列振子以同一个频率一起摆动。

一步步重演推导

下面五步，从“场像弹簧”这个图像出发，走到“光子是场的激发”。点“下一步”，一次看一步。

先做一次拆解。想象空间被划成许多小格，每格有一个场值。场值为零时这格没有能量；场值偏离零，就像弹簧被拉开，要储存能量。相邻格子的场值不一样，互相拉扯，这一份拉扯也储存能量。麦克斯韦方程描述的，正是这种“每格一个振子、格子之间用弹簧相连”的系统。

连续场只是格子无限细的极限。做法是把这个由无数耦合振子组成的系统按正弦波分解。每一列正弦波是一个“模式”，有确定的波长，也就有确定的频率。分解之后各模式互不耦合，每一个都单独做简谐振动。到这里，场的问题变成了一堆独立弹簧的问题。

现在把每个模式当成一个量子谐振子。经典弹簧的能量可以连续取任意值；量子弹簧不行。它的能级是等间距的，间隔为 ħω，最低一档不是零，而是 ½ħω。

En = ( n + ½ ) ħω，n = 0, 1, 2 …

读作：第 n 档的能量，等于 n 加二分之一，再乘 ħ 和角频率。n 只能取非负整数，所以能量只能一格一格地排。

  • Eₙ第 n 档的能量
  • n能级编号，也是光子数
  • ħ约化普朗克常数，约 1.055×10⁻³⁴ J·s
  • ω这个模式的角频率

相邻两档差多少？把 n 换成 n+1 再相减，多出来的正好是 ħω。也就是说，要让这个模式从第 n 档升到第 n+1 档，必须一次交给它 ħω；少一点不行，多一点会直接跳到更高档。反过来，降一档就交出 ħω。

En+1 − En = ħω

读作：相邻两档的能量差恒等于 ħω，与 n 无关。所有台阶一样高，不存在“半级台阶”可走。

台阶高度只由频率决定：频率越高，升一档要付的能量越多。

这个“一档”在实验上是什么？它就是光子。角频率与频率的关系是 ν=ω/2π，于是 ħω=hν。模式升一档，场里多出一份 hν 的能量；在探测器上，这份能量表现为一个频率为 ν 的光子被吸收。降一档，就是放出一个光子。

E = ħω = hν

读作：一档的能量等于 ħ 乘角频率，也等于 h 乘频率。两种写法只差一个 2π，说的是同一份能量。

于是“光子”不是一颗小钢珠，而是电磁场某个模式被激发了一档。模式有无数个，频率各不相同，所以光子的能量可以不同：红光的光子能量小，蓝光的大，γ 射线更大。但在同一个模式里，光子只能整份加上去或减下来。

还有个细节不能漏：n=0 时能量不是零。最低档是 ½ħω，叫零点能。它不对应“半个光子”，也不能被拿走——你能做的最多是把 n 从 1 降到 0，交出的仍然是 ħω。零点能在 1948 年由卡西米尔提出，1997 年由兰莫勒用扭摆做了精确测量：两块靠得很近的金属板之间，允许的场模式比外面少，零点能就产生微小压力，把两块板往一起推。

于是“光子数 n”有了清楚的含义：它数的是这个模式被激发到了第几档。n 从 0 变到 1、2、3……，每次变化一格，对应吸收或放出一个光子。n 不是“场里有几个小球”，而是“这个振子爬到了第几级台阶”。

动手看看

左边是振子的能级阶梯，台阶高度按 (n+½)ħω 排布，间距处处相同。右边是同一个振子的弹簧模型：n 越大，能量越高，振幅越大。点下面的按钮让振子升一档或降一档，看两边的读数一起变。

演示 · 场的振子：升一档 = 一个光子 Eₙ = (n + ½)ħω

ħω 取 532 纳米绿光的值，即 2.33 eV。每按一次“吸收”，n 加 1，振子振幅变大，能量增加一个 2.33 eV；按“发射”则相反。n=0 时振幅不为零，因为零点能还在。

试试：连按八次“吸收”，看阶梯上的亮点一级一级往上爬，弹簧越摆越大；再按“发射”，能量一次减掉 2.33 eV，n=0 之后按不动了。

代进真实数字

拿一束绿光算一算。波长 532 纳米，是倍频 Nd:YAG 激光的典型波长，绿色激光笔都用它。

E = h cλ = 1240532 eV·nm / nm ≈ 2.33 eV

读作：光子能量等于 hc 除以波长。hc 约等于 1240 电子伏乘纳米，除以 532 纳米，得到 2.33 电子伏。

2.33 eV 是什么概念？可见光的能量大致在 1.8 到 3.1 eV 之间，2.33 eV 落在中间偏绿的位置；一节 1.5 伏干电池给电子加速，能量才 1.5 eV。单个光子的能量，和单个电子经过几伏电压获得的能量是同一量级。

再看功率。1 瓦的绿光激光每秒输出 1 焦耳。每个光子 2.33 eV，换成焦耳是 2.33×1.602×10⁻¹⁹，约 3.73×10⁻¹⁹ 焦耳。

N = PE = 13.73×10−19 ≈ 2.7×1018 个/秒

读作：每秒光子数等于功率除以单个光子的能量，约 2.7 乘 10 的 18 次方个。这个数字比地球上的人口多十亿倍。

数量级的意思在这里：日常光源的光子多到数不清，所以光看起来是连续的；到了极弱的光，光子就一颗一颗显形。生理实验估计，人眼在充分暗适应后，几十个光子就能引起一次微弱的光感。

这个结论当年改变了什么

场量子化是量子场论的起点。1927 年，狄拉克把电磁场写成量子振子的集合，第一次定量算出原子对光子的吸收与发射；爱因斯坦 1916 年用半经典论证得到的自发辐射系数，在这里被推导了出来。1928—1929 年，这套方法被推广到电子场和更一般的场。

这套语言后来成了标准模型的地基。电子场、夸克场、希格斯场，全都是“每一点挂一个振子”的场；粒子的产生与湮灭，就是振子升一档、降一档。2012 年发现的希格斯玻色子，本质上就是希格斯场被激发了一档。

它还改变了“真空”这个概念。n=0 的真空不是“什么都没有”：每个模式都保留着 ½ħω 的零点能，还可能有场的短暂涨落。真空成了一个有结构的对象。
